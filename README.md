## About

I'm a Computer Science undergraduate and product-oriented software developer who enjoys taking ideas from problem discovery to usable software. My work spans full-stack development, backend systems, data-driven applications, and applied AI/ML.

- 🚀 Building **[Snapmeet](https://snapmeet.co.in/)** — an event management SaaS platform with 800+ users.
- 🧠 Developing **KAIRO** — an AI-powered engineering knowledge and handoff platform.
- 📊 Working on **PRISM** — *Predictive Root-Cause Intelligence for Strategic Metrics*.
- ⚙️ Interested in backend architecture, API design, databases, system performance, and product engineering.
- 🌱 Learning by building, testing, and improving real projects.

> **My approach:** Understand the problem → design the solution → build thoughtfully → measure → improve.
